# -MAEK7-Beauty-Style
💄 MAEK7 Beauty &amp; Style – الذكاء الاصطناعي لتحليل الجمال والموضة
هذا تطبيق متكامل بالذكاء الاصطناعي يستطيع تحليل صورة شخصية ويقدم:

تسريحات شعر مناسبة لشكل الوجه ونوع الشعر.

ألوان ماكياج مناسبة (أحمر شفاه، ظلال عيون، كونتور) حسب لون البشرة وملامح الوجه.

حلول لمشاكل البشرة مثل حب الشباب، الهالات السوداء، البقع الداكنة.

نصائح للعناية بالجسم والبشرة مخصصة.

كيف يعمل؟

ترفع المستخدمة صورة شخصية واضحة.

يرسلها التطبيق إلى Gemini 2.5 Flash مع وصف المهمة.

يحلل الذكاء الاصطناعي ملامح الوجه، شكل الوجه، لون البشرة، الشعر، وأي مشاكل جلدية ظاهرة.

يعرض النتائج بطريقة أنيقة مع صور توضيحية افتراضية (تمثيلية) لكل اقتراح.

ملاحظة: التطبيق لا يعدل الصورة ولا يولد صوراً حقيقية جديدة (لأن Gemini Vision لا يقوم بذلك مباشرة)، لكنه يعطي أوصافاً دقيقة ومرئيات وصفية يمكن للمستخدمة أن تتخيلها. للإصدارات المستقبلية يمكن دمجه مع نماذج توليد الصور مثل Stable Diffusion أو DALL‑E.🎯 ماذا يقدم هذا التطبيق تحديداً؟
المجال	الاقتراحات
تسريحات شعر	حسب شكل الوجه (دائري، بيضاوي، مربع، قلب) ونوع الشعر (ناعم، مجعد، خفيف).
ماكياج	ألوان أحمر شفاه وظلال عيون وبلاشر تناسب درجة لون بشرتك (فاتحة، متوسطة، سمراء، سوداء).
حلول مشاكل البشرة	حب الشباب، الهالات السوداء، البقع الداكنة، الجفاف، الخطوط الدقيقة – مع مكونات طبيعية (عسل، ألوفيرا، فيتامين C) أو منتجات مقترحة.
نصائح يومية	ترطيب، حماية من الشمس، نظافة البشرة، نظام غذائي مفيد، روتين ليلي.
ملاحظة مهمة: الصور المعروضة داخل البطاقات هي صور رمزية لأن Gemini لا يولد صوراً، لكن النص الوصفي دقيق جداً. في الإصدارات المستقبلية يمكن دمج التطبيق مع DALL‑E API أو Stable Diffusion لتوليد صور حقيقية للشعر والماكياج بناءً على وجه المستخدمة.

💡 أفكار للتطوير (المستوى الاحترافي)
دمج مولد صور حقيقية:

عند الحصول على وصف التسريحة أو الماكياج، يمكن إرسال الوصف إلى نموذج توليد الصور (مثل Stability AI أو OpenAI DALL‑E) لإنشاء صورة افتراضية للمستخدمة بالشكل الجديد.

تحليل بشرة أكثر دقة:

استخدام مكتبة TensorFlow.js للكشف عن حب الشباب والتجاعيد قبل إرسال الصورة إلى Gemini، مما يزيد الدقة.

توصيل مع متاجر التجميل:

عرض روشراء المنتجات المذكورة مباشرة (Amazon, Noon, Sephora) عبر روابط تابعة.

تطبيق موبايل كامل:

تحويل هذا الكود إلى تطبيق باستخدام Capacitor أو React Native للوصول للكاميرا مباشرة.

🚀 كيف تستخدمين التطبيق الآن؟
احفظي الكود كاملاً باسم MAEK7_Beauty_Style.html.

افتحي الملف في متصفح (Chrome / Edge).

احصلي على مفتاح Gemini API من Google AI Studio (مجاني).

الصقي المفتاح في الحقل العلوي.

ارفعي صورة شخصية (يفضل وجه مكشوف بإضاءة طبيعية).

اضغطي "تحليل ملامحي" وانتظري قليلاً.

استمتعي بالتوصيات المصممة خصيصاً لكِ!
